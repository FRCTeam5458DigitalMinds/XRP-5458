## XRP-5458

A XRP training repository for FRC Team 5458 (Digital Minds) developers, covering the fundamentals of FIRST Robotics programming.


### File Overview:

- `src/main/java/frc/robot/Main.java` — Entry point of the application.
- `src/main/java/frc/robot/Robot.java` — Handles robot lifecycle: disabled, autonomous, teleop, test.
- `src/main/java/frc/robot/RobotContainer.java` — Connects subsystems, commands, controllers, and autonomous routines.
- `src/main/java/frc/robot/Constants.java` — Fixed values for system wide settings.
- `src/main/java/frc/robot/subsystems/Drivetrain.java` — Drivetrain subsystem.
- `src/main/java/frc/robot/subsystems/Arm.java` — Arm subsystem.
- `src/main/java/frc/robot/commands/ArcadeDrive.java` — Arcade drive subsystem.
- `src/main/java/frc/robot/commands/AutonomousDistance.java` — Autonomous driving by distance commands.
- `src/main/java/frc/robot/commands/AutonomousTime.java` — Autonomous driving by time commands.
- `src/main/java/frc/robot/commands/DriveDistance.java` — Command to drive specific distance.
- `src/main/java/frc/robot/commands/DriveTime.java` — Command to drive for a set time.
- `src/main/java/frc/robot/commands/TurnDegrees.java` — Command to turn a set degree.
- `src/main/java/frc/robot/commands/TurnTime.java` — Command to turn for a set time.
